# 🐾 ONG Patas Amigas

Projeto acadêmico desenvolvido com **HTML, CSS e JavaScript**, com o objetivo de criar uma página web para uma ONG fictícia voltada ao cuidado, proteção e adoção responsável de animais.

🌐 **Acesse o projeto:**  
https://elasoares.github.io/ong-patas-amigas/

---

## 📌 Sobre o projeto

A **ONG Patas Amigas** é uma página web desenvolvida como projeto acadêmico para colocar em prática conhecimentos de desenvolvimento Front-End.

A proposta do projeto é apresentar uma página institucional simples e responsiva para uma organização fictícia de proteção animal, oferecendo informações sobre:

- 🐶 Adoção de animais
- ❤️ Cuidados com pets
- 💉 Calendário de vacinação
- 🏠 Formas de ajudar
- 🤝 Trabalho voluntário
- 📩 Formulário de contato
- 📍 Localização da ONG

O projeto também busca trabalhar conceitos de **estruturação HTML, estilização com CSS e interações utilizando JavaScript**.

---

## 🚀 Funcionalidades

### 🐕 Adoção

A página apresenta animais disponíveis para adoção, com informações como:

- Nome
- Espécie
- Idade
- Porte
- Vacinação
- Castração

Também existe a opção **"Quero adotar"** para representar o processo de interesse na adoção.

### 🩺 Dicas de cuidados

A página apresenta informações básicas sobre cuidados com animais, incluindo:

- Alimentação saudável
- Higiene
- Saúde
- Vacinação
- Vermifugação
- Passeios e brincadeiras

Também foi criada uma tabela com informações sobre algumas vacinas para cães e gatos.

### 🤝 Como ajudar

São apresentadas diferentes formas de contribuir com a ONG:

- Adotar
- Doar
- Ser voluntário
- Oferecer lar temporário

### 📍 Localização

A página possui um mapa incorporado para representar a localização da ONG.

### 📩 Formulário de contato

Foi desenvolvido um formulário contendo campos para:

- Nome completo
- E-mail
- Telefone
- Assunto
- Mensagem

O formulário também possui validações básicas utilizando os recursos do próprio HTML.
